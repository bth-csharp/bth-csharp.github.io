## <Icon name="open-book" class="inline-icon" label="Interpret code" /> Tolka kod (del 2)

1. Beskriv klassen? Peka ut konstruktorn och attribut. Hur många objekt skapas? Vad finns i variabeln `dog1`? Vilket namn finns lagrat i respektive objekt? Vad skrivs ut när programmet körs?

```csharp
class Dog
{
    private string _name;

    public Dog(string name)
    {
        this._name = name;
    }

    public void Bark()
    {
        Console.WriteLine($"{this._name} säger voff!");
    }
}

Dog dog1 = new Dog("Bella");
Dog dog2 = new Dog("Max");

dog1.Bark();
dog2.Bark();
```

2. Vad gör följande kod och vad blir utskriften och varför? Hur gammal är personen när objektet skapas? Vad gör metoden `Birthday()`?

```csharp
class Person
{
    private string _name;
    private int _age;

    public Person(string name, int age)
    {
        this._name = name;
        this._age = age;
    }

    public void Birthday()
    {
        this._age++;
    }

    public void PrintInfo()
    {
        Console.WriteLine($"{this._name} är {this._age} år.");
    }
}

Person person = new Person("Anna", 20);

person.Birthday();
person.Birthday();

person.PrintInfo();
```

3. Givet klassen nedan, kan du skapa ett objekt av klassen Cat? Motivera! Hur många konstruktorer har klassen Person ovan?

```csharp
class Cat
{
    private string _name;

    public void PrintInfo()
    {
        Console.WriteLine($"Katten heter {this._name}.");
    }
}

```

## <Icon name="seti:csharp" class="inline-icon" label="Write code" /> Praktisk uppgift

Börja med att planera er lösning, vilken kod behövs och vilka datatyper er data kommer ha i de olika stegen. Efter ni har en plan, skriv koden. Använd frågorna nedanför för att planera koden ni behöver för att lösa uppgiften.

- Går det att identifiera delproblem som kan lösas för att testa tidigt?
  - Vilka delproblem i så fall?
  - Hur kan du testa dessa?
- Ge förslag på lämpliga variabler och vilken datatyp de ska innehålla
- Vilken/Vilka språkkonstruktion/er behövs?
- Vad börjar du med?
- Formulera en lösning i [pseudo-kod](https://sv.wikipedia.org/wiki/Pseudokod)
- diskutera alternativa lösningar

### Uppgifter

Skapa ett terminalprogram som heter **Shapes**. Avrunda utskrifterna av beräkningarna till 2 decimaler i utskriften.

1. Gör en klass **Rectangle** med de privata variablerna bredd och höjd samt en konstruktor med inparametrarna för bredd och höjd. Gör get- och setmetoder till de privata variablerna. Det ska inte vara möjligt att sätta ett negativt värde, då ska värdet inte ändras. I konstruktorn ska ett negativt värde sättas till 0. Dessutom har klassen **Rectangle** metoderna:  
   - arean: `CalculateArea()` som är publik och returnerar en double
   - omkretsen: `CalculatePerimeter()` som är publik och returnerar en double
   - lägg till en defaultkonstruktor (sätt attributen till lämpliga värden)

1. Gör en klass **Circle** med den privata variabeln radie. Den har samma metoder som klassen **Rectangle** samt inga negativa värden.

1. Testa klasserna **Rectangle** och **Circle** i ditt huvudprogram.

1. Skapa en array med plats för 4 objekt av typen **Circle** i ditt huvudprogram. Skapa 4 olika objekt av klassen **Circle** och skriv ut arean och omkretsen för alla i en foreach-loop.

1. Gör om förra uppgiften med en lista istället.

### Extra uppgift "Unika Tal"

Du ska skapa en klass som heter **Number**. Varje instans av klassen representerar ett heltal och har en metod som avgör om talet är **primtal**, **jämnt**, eller **palindromiskt** (samma framifrån och bakifrån).

Skapa sedan en lista med `Number`-objekt för talen 10 till 99. Skriv ut alla tal som uppfyller **exakt två** av dessa tre egenskaper.

**Krav:**

1. Skapa en klass **Number** med:
   - Ett `int`-attribut för talet.
   - En metod `IsPrime()`
   - En metod `IsEven()`
   - En metod `IsPalindrome()`

2. I `Program.cs`:
   - Skapa en `List<Number>` med alla tal från 10 till 99.
   - Gå igenom listan och skriv ut de tal som uppfyller **exakt två** av de tre egenskaperna.

**Tips:**

- Palindromkontroll kan göras med heltal: till exempel 42 blir 24 vilket kan översättas med 2 * 10 + 4 = 24. Och 24 ≠ 42 alltså är det inte ett palindrom.
- Du kan använda modulus och division för att plocka ut siffror.
- Använd `List<Number>` och en `foreach`-loop.
