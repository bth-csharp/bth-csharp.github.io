Tidigare har vi enbart skapat körbara konsolprojekt med `dotnet new console`. Ibland vill vi skapa klassbibliotek med återanvändbar kod som fler projekt kan använda. Då kan vi skapa biblioteksprojekt med `dotnet new classlib`. Biblioteksprojekten är inte körbara utan används i konsolprojekt.

Genom att dela upp programmet i ett konsolprojekt och ett klassbibliotek (class library) separerar vi användargränssnittet från logiken. Menu visar information och tar emot input, medan klasserna i MyLibrary gör själva arbetet. Klassbiblioteket MyLibrary blir ingen körbar applikation som kan köras med `dotnet run`. Filerna kompileras istället till en DLL-fil (Dynamic Link Library). Denna DLL-fil kan användas av konsolprojektet. Konsoleprojektet är körbart med `dotnet run` och byggs till EXE (Executable).

## Skapa ett klassbibliotek

Vi börjar med att skapa en katalog `classlibPractice` i `kmom05/practice`-katalogen och går ner i den.

Vi skapar ett klassbibliotek med följande kommando:

```bash
dotnet new classlib -n MyLibrary

tree -L 2
// ger utskriften:
// .
// ├── MyLibrary
// │   ├── Class1.cs
// │   ├── MyLibrary.csproj
// │   ├── bin
// │   └── obj
```

Vi byter namn på klassen och filen (Class1.cs) till `Calculator` och lägger till en metod.

```csharp title="Klassen Calculator.cs i klassbiblioteket MyLibrary"
namespace MyLibrary;

public class Calculator
{
    public static int Add(int a, int b)
    {
        return a + b;
    }
}
```

## Skapa konsolprojekt

Nu skapar vi konsolprojektet `MyApp` i `classlibPractice`-katalogen som du skapade i `kmom05/practice`-katalogen. Konsolprojektet `MyApp` ska använda klassbiblioteket `MyLibrary`.

```bash title="Terminalen"
dotnet new console -n MyApp

tree -L 2
// ger utskriften:
// .
// ├── MyApp
// │   ├── MyApp.csproj
// │   ├── Program.cs
// │   └── bin
// │   └── obj
// ├── MyLibrary
// │   ├── Calculator.cs
// │   ├── MyLibrary.csproj
// │   ├── bin
// │   └── obj
```

Vi lägger till en referens till klassbiblioteket `MyLibrary` i konsolprojektet `MyApp` i terminalen.

```bash title="Terminalen"
cd MyApp
dotnet add reference ../MyLibrary/MyLibrary.csproj
```

Vi kontrollerar att referensen till klassbiblioteket finns i "MyApp/MyApp.csproj".

## Kör konsolprojektet

Vi uppdaterar först konsolprojektet med kod som anropar klassbiblioteket och därefter testkör vi.

```csharp title="I MyApp/Program.cs"
using MyLibrary;

Console.WriteLine($"2 + 3 = {Calculator.Add(2, 3)}");
// Ger utskriften:
// 2 + 3 = 5

```

## Skapa ett testprojekt som testar klassbiblioteket

Vi skapar ett testprojekt i katalogen `classlibPractice`. Vi lägger också till en referens till klassbiblioteket "MyLibrary".

```bash title="Terminalen"
dotnet new nunit -n MyLibrary.Tests
dotnet add MyLibrary.Tests/MyLibrary.Tests.csproj reference MyLibrary/MyLibrary.csproj
tree -L 1
// ger utskriften:
// .
// ├── MyApp
// ├── MyLibrary
// ├── MyLibrary.Tests
// └── classlibPractice.sln
```

### Lägg till ett testfall

Vi uppdaterar `MyLibrary.Tests/UnitTest1.cs` och byter namn på testklassen till **CalculatorTest** och därmed också på filen till `CalculatorTest.cs`:

```csharp title="Enhetstester i klassen CalculatorTest"
using MyLibrary;

namespace MyLibrary.Tests;

public class CalculatorTest
{
    [Test]
    public void TestAddPositiveNumbers()
    {
        Assert.That(Calculator.Add(6, 4), Is.EqualTo(10), "The sum should be 10.");
    }

    [Test]
    public void TestAddNegativeNumbers()
    {
        Assert.That(Calculator.Add(6, -4), Is.EqualTo(2), "The sum should be 2.");
    }
}

```

Vi kör testfallet med `dotnet test MyLibrary.Tests/MyLibrary.Tests.csproj` eller gå ner i `MyLibrary.Tests`-katalogen och kör `dotnet test`.
