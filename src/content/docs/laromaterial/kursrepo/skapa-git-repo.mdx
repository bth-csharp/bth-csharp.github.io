Nu skall du skapa kursens Git-repo lokalt i din terminal under katalogen `dbwebb-kurser` genom att klona repot som du nyligen skapade på GitHub.

## Gå till dbwebb-kurser

Börja med att gå till din arbetskatalog för kurserna, den som du döpte till `dbwebb-kurser`.

```bash title="Gå till katalogen dbwebb-kurser"
# Gå till hemmakatalogen
cd

# Gå till dbwebb-kurser
cd dbwebb-kurser
```

Du kan göra samma sak i ett kommando och här refererar `~` till din hemmakatalog.

```bash title="Gå till katalogen dbwebb-kurser, i ett kommando"
cd ~/dbwebb-kurser
```

Använd kommandot `pwd` och `ls` för att försäkra dig om att du är på rätt plats i filsystemet.


## Klona ditt GitHub repo

Logga in på [GitHub](https://github.com/) där ska du ha fått ett kursrepo som heter csharp-xxxx## där xxxx## är ditt studentkonto med fyra tecken och två siffror, tex abcd26 eller motsvarande.  
Ett annat sätt att hitta länken till ditt kursrepo är i Canvas, under "Omdöme" och klicka på kommentaren (pratbubblan) vid uppgiften "GitHub invite".

Det är bara du själv och lärarna i kursen som har tillgång till ditt kursrepo.

Nu ska vi skapa en lokal kopia av ditt GitHub repo genom att klicka på "Code" och kopiera SSH-länken.

```bash title="Kommandon för att klona ditt kursrepo"
git clone git@github.com:bth-csharp/csharp-<akronym>.git
```

Om din akronym är `abcd26` så ser kommandot ut så här:  
`git clone git@github.com:bth-csharp/csharp-abcd26.git`


### Kolla ditt lokala Git-repo

Flytta till ditt lokala kursrepo med `cd` och så namnet på ditt kursrepo.

Du kan använda kommandot `pwd` och `ls` för att kontrollera vilken katalog du är i och vad den innehåller. Använder du `ls -la` får får du detaljer om filer och kataloger och det visas även dolda kataloger som börjar med en punkt `.`.

### Installera task

Om du saknar kommandot `task`, installera så här:

#### Ubuntu (Windows/Linux)

```console title="Installera Task med Snap."
sudo snap install task --classic
```

#### Mac

```console title="Installera Task med Homebrew."
brew install go-task
```

#### Verifiera installationen av Task

`task` är kommandot för att köra programmet Task och sen finns det flaggor som till exempel; `--list` är en flagga som listar alla kommandon som finns i Taskfile.

```console title="Verifiera installationen av Task"
task --version // ger i mitt fall utskriften: 3.45.0, ni får kanske nyare
task --help // ger hjälp
task --list // listar aktuella kommandon
```

<details>
<summary>
#### Problem vid installation av task?
</summary>

**Råkat stänga av eller något hänt som fått det att krascha?**

- Kolla status med `snap changes`  
Du kommer se olika ID, Status, Summary och lite mer, men ID och Status är dem relevanta.
Bör stå "Error" efter en status som gäller för Install "task" snap
Vi behöver avbryta den med "Error" för "task". 
- Skriv följande: `sudo snap abort <relevant ID>` Exempelvis sudo snap abort 2
- Starta om terminalen via `sudo systemctl restart snapd`
- Prova installera igen `sudo snap install task --classic`

**Fått upp något i stil med**
*Warning: The unit file, source configuration file or drop-ins of snapd.service changed on disk. Run 'systemctl daemon-reload' to reload units.*
Då gör du som den säger och skriver
- `sudo systemctl daemon-reload`
- `sudo systemctl restart snapd`
Nu bör det vara okej att installera igen
- `sudo snap install task --classic`

Repetera från början om något skulle gå fel igen

**Alternativ sätt för att installera task:**
```bash
curl -1sLf 'https://dl.cloudsmith.io/public/task/task/setup.deb.sh' | sudo -E bash
sudo apt install task
```

</details>

### Kör setup i ditt lokala Git-repo

Nu kan du köra följande kommando för att göra ditt kursrepo redo. Kommandot skapar kataloger, laddar ner workflow-fil & task-fil samt tester. Dessutom skapas en branch för Canvas-uppgiften "Test gitconfig" `bth/submit/test-gitconfig` samt första inlämningsbranchen `bth/submit/kmom03`.

```bash title="Kommando för att göra ditt lokala kursrepo redo"
pwd // visar att du står i ditt lokala repo dbwebb-kurser/csharp-abcd26 för studenten abcd26

task setup
```

I slutet av setup-skriptet körs en del tester. Vid eventuella fel så kör du de kommandon som föreslås.

När alla testerna gått igenom är det bara att köra på!  Så här ser det ut i din terminal när `task setup` gått igenom:

### Ladda upp de lokala ändring till GitHub

När du körde `task setup` så uppdaterades några filer och de ska du pusha upp till kursrepot på GitHub. Det kan se olika ut beroende på vilka filer som uppdaterades.

import git_status_after_task_setup_ok from '@assets/kursrepo/git_status_after_task_setup_ok.png';

<Figure 
    src={git_status_after_task_setup_ok}

Gör sedan `git add .`, `git commit -m "Update after task setup"` och `git push`. Dubbelkolla att filerna finns på GitHub.

Om du inte får några filer att checka in efter `task setup` kan du uppdatera i filen `README.md` istället.

En mer utförlig guide om hur du gör med git hittar du i python-kursen [Uppdatera fil i git repot](https://bth-python.github.io/laromaterial/kursrepo-utvecklingsmiljo/gitadd/).


### Om något går fel...

:::caution
Om något går fel så kan du radera din katalog (ditt repo lokalt) och försöka igen.

```bash title="Så här raderar du ditt lokala repo om du vill börja om från början."
# Om du till exempel vill ta bort det lokala kursrepot csharp-abcd26, gör så här:
cd ~/dbwebb-kurser
rm -rf csharp-abcd26
```

Kör därefter kommandona som klonar ditt lokala kursrepo igen och därefter setup-skriptet enligt ovan.
:::
